# 봉황 만리장성 수리 영상 분석기

신바람 봉황 서버의 만리장성 수리 퀘스트는 10,000회가 목표다. 벽돌이 소진되면 국내성 털보네대장간에서 **한 번에 100개**를 구매하는 기준을 사용한다. 구매 영상의 2개는 소진 상황을 보여주기 위한 수량이다.

## 실행

Windows x64에서 .NET 10 SDK로 프로젝트 루트에서 실행한다. 첫 빌드에서 NuGet이 OpenCvSharp와 Windows용 네이티브 라이브러리를 복원한다.

녹화 영상 네 개는 프로젝트 루트의 `public` 폴더에 있다.

```powershell
dotnet build -c Release
dotnet run -c Release
dotnet run -c Release -- 'public/벽돌구매.mp4'
```

기본 입력은 `public/만리장성수리.mp4`다. 입력 영상은 제공 영상과 같은 1920×1080 UI 배치를 사용해야 한다. 수리 대화에서 벽돌 사용 문구를 찾으면 소모 1개로 집계한다. 같은 결과창이 여러 프레임에 걸쳐 보여도 균열 한 건에 한 번만 센다. 보유량은 제공 영상에서 확인한 2개·1개·항목 사라짐을 판독한다. 그 밖의 수량은 수량 표기가 보이는지 기록한다.

벽돌 항목이 사라지거나 현재 구매분의 누적 소모가 100개에 도달하면 국내성 재구매 시점을 출력한다.

## 영상에서 확인한 동선과 시각

| 영상 | 대략적인 영상 시각 | 화면에서 확인한 내용 |
| --- | --- | --- |
| 벽돌구매 | 00:00–00:04 | 국내성에서 비영사천문 방향 입력 안내가 나온 뒤 `(15,108)` 부근으로 이동한다. |
| 벽돌구매 | 00:05–00:12 | 다리를 건너 `(40,121)`, `(53,123)`, `(59,122)` 부근을 지나 털보네대장간 `(5,9)`로 들어간다. |
| 벽돌구매 | 00:13–00:18 | 왼쪽 NPC에서 `물건 사기 → 벽돌 → 몇 개나 필요하신가요?` 순으로 진입한다. 구매 목록의 단가는 100이고, 영상에서는 구매 후 `벽돌 2개`가 표시된다. 실제 구매 기준은 100개다. |
| 만리장성수리 | 00:05–00:10 | 장안성 북문 `(115,9)` 부근에서 위로 이동해 지역 지도를 연다. 장안성에서 연결된 만리장성을 선택하면 만리장성3 `(16,46)`에서 시작한다. |
| 만리장성수리 | 00:12–00:14 | 만리장성3 내부를 이동한다. 이 구간에는 수리 대화창이 없다. |
| 만리장성수리 | 00:14–00:16 | `(16,14)`에서 균열 안내 후 벽돌이 부서졌다는 문구가 나온다. 재고는 2개에서 1개로 줄어든다. |
| 만리장성수리 | 00:19–00:22 | `(42,21)`에서 균열 안내 후 벽돌을 사두길 잘했고 어서 고치자는 문구가 나온다. 재고에서 마지막 벽돌이 사라진다. |

조작 키는 인수인계 기준으로 국내성비서 `U → M`, 장안성비서 `U → C`, 비영사천문 숫자패드 `9`, 풍신보 숫자 `2`다.

## 허풍선 영상 검토 기록

두 영상 모두 1920×1080이다. 아래 시각은 각 파일의 재생 시각이다.

| 영상 | 문제 창 표시 구간 | 사람이 화면에서 확인한 내용 |
| --- | --- | --- |
| `허풍선영상.mp4` | 약 00:05.1–00:15.8 | 좌하단에 움직이는 한글 여섯 글자와 입력란이 표시된다. 약 00:15.0에서 제출된 입력값을 볼 수 있다. |
| `허풍선영상.mp4` | 약 00:23.5–00:35.0 | 돌길 배경의 다람쥐 문제에서 맨 오른쪽 다람쥐를 선택했다. |
| `허풍선영상.mp4` | 약 00:43.6–00:54.8 | 동굴 배경의 다람쥐 문제에서 맨 왼쪽 다람쥐를 선택했다. |
| `허풍선영상2.mp4` | 시작부터 약 00:08.5까지 | 시작 프레임에 문자 문제가 떠 있다. 통과한 입력값은 `사다마사주람`이다. |

네 장면 모두 오른쪽 메시지창에서 통과 기록을 확인했다. 첫 영상에서는 NPC 대화창과 문자 문제 창이 동시에 표시됐고, 캐릭터가 말한 ‘앗~~ 허풍선이다!’는 문제 창이 닫힌 뒤에도 채팅에 남았다. 문자형은 글자마다 기울기와 선명도가 달라져 프레임마다 읽기 쉬운 부분이 바뀐다. 위 표는 수동 판독 기록이며, 현재 콘솔에서 검증한 기능은 아래 벽돌 소모 집계다.

## 검증 결과

수리 영상에서 눈으로 확인한 벽돌 소모 2건과 콘솔 집계가 일치했다.

| 처음 표시된 시각 | 재고 변화 | 콘솔 기록 |
| --- | --- | --- |
| 00:15.466 | 2개 → 1개 | 소모 1개 |
| 00:20.716 | 1개 → 0개 | 소모 1개, 국내성에서 100개 재구매 안내 |

구매 영상에서는 소모 0개를 기록했다. 첫 수리 장면을 101회 반복한 검증 영상에서는 100번째에서 재구매 시점이 한 번 표시됐다. Release 빌드는 경고와 오류 각각 0개로 완료됐다.
